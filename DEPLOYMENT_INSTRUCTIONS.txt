STEP 2: SET UP FREE DATABASE (Choose ONE option)
═══════════════════════════════════════════════════════════════════════════

OPTION A: Aiven MySQL (RECOMMENDED - 100% Free)
────────────────────────────────────────────────
1. Go to: https://aiven.io/
2. Sign up for free account
3. Click "Create Service" → Select "MySQL"
4. Choose:
   - Cloud: AWS
   - Region: Any (closest to you)
   - Plan: "Startup-4" (FREE tier)
5. Service name: "curalink-db"
6. Click "Create Service" (wait 3-5 minutes for deployment)
7. Once running, click on the service → "Overview" tab
8. Copy the "Service URI" - it looks like:
   mysql://username:password@host:port/defaultdb
9. Save this URL - you'll need it for environment variables

OPTION B: FreeSQLDatabase.com (Alternative - 100% Free)
────────────────────────────────────────────────────────
1. Go to: https://www.freesqldatabase.com/
2. Fill the form:
   - Database Name: curalink
   - Email: your-email@example.com
3. Click "Create Database"
4. Check your email for database credentials
5. Construct your DATABASE_URL:
   mysql+pymysql://username:password@host:port/database_name
6. Save this URL - you'll need it

OPTION C: Koyeb PostgreSQL (Alternative - 100% Free)
─────────────────────────────────────────────────────
1. Go to: https://www.koyeb.com/
2. Sign up for free account
3. Go to "Databases" → "Create Database"
4. Choose PostgreSQL, select free tier
5. Database name: "curalink"
6. Wait for deployment (2-3 minutes)
7. Copy the connection string from dashboard
8. Save this URL - you'll need it

STEP 5: DEPLOY FRONTEND TO NETLIFY (100% Free)
════════════════════════════════════════════════════════════════════════

1. Go to: https://www.netlify.com/
2. Sign up or log in
3. Click "Add new site" → "Import an existing project"
4. Connect to GitHub and select your "curalink" repository
5. Configure build settings:
   
   Branch to deploy: main
   Base directory: curalink-frontend
   Build command: npm run build
   Publish directory: .next
   
6. Click "Show advanced" → "New variable"
   
   Environment Variables (CRITICAL - Add these):
   ──────────────────────────────────────────────
   NEXT_PUBLIC_API_URL = https://your-backend-app.koyeb.app
   NEXT_PUBLIC_WS_URL = wss://your-backend-app.koyeb.app
   
   (Replace "your-backend-app.koyeb.app" with YOUR actual Koyeb URL from Step 4)
   
7. Click "Deploy site"
8. Wait 2-4 minutes for deployment
9. Once deployed, you'll get a URL like: https://random-name.netlify.app
10. Click "Site settings" → "Change site name" to customize
11. Your frontend is now live!

IMPORTANT NOTES:
- Netlify free tier: Unlimited sites, 100GB bandwidth/month
- Automatic HTTPS enabled
- Auto-deploys on git push to main branch

STEP 7: TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

If Backend (Koyeb) fails to deploy:
────────────────────────────────────
1. Check Koyeb logs: Dashboard → Your App → Logs
2. Common issues:
   - Missing environment variables → Add all from Step 4
   - Database connection failed → Verify DATABASE_URL format
   - Port binding error → Ensure PORT=8000 in env vars

If Frontend (Netlify) fails to build:
──────────────────────────────────────
1. Check Netlify deploy logs
2. Common issues:
   - Build command failed → Check package.json scripts
   - Missing env vars → Add NEXT_PUBLIC_* variables
   - Out of memory → Contact Netlify support (rarely happens)

If WebSocket doesn't connect:
──────────────────────────────
1. Check browser console for errors
2. Verify NEXT_PUBLIC_WS_URL uses "wss://" (not "ws://")
3. Verify backend is running: visit backend-url/health
4. Koyeb supports WebSocket by default - should work automatically

If Database connection fails:
──────────────────────────────
1. Test database connection from backend logs
2. Verify DATABASE_URL format:
   - MySQL: mysql+pymysql://user:pass@host:port/db
   - PostgreSQL: postgresql://user:pass@host:port/db
3. Check database service is running in provider dashboard
4. Verify IP whitelist (if required by provider)
